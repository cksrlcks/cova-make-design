# 앱 화면 시안 (제품 유형 · 모바일 앱 / 소비자형 웹 앱)

인터뷰 라운드 P에서 **플랫폼 = 모바일 앱**(또는 둘 다)이거나, 소비자형 웹 앱일 때 읽는다.
도구형·어드민형은 [saas-admin.md](saas-admin.md)가 우선이다. Mobbin iOS 실앱(패션·뷰티·F&B·여행·
음악·피트니스·핀테크·명상·교육·AI 등 약 70개 앱)의 화면·플로우를 직접 보고 정리했다(2026-09).

> **핵심 원리.** 앱 시안이 밋밋한 이유는 **모든 것이 같은 크기의 흰 카드**라서다 — radius 12 카드,
> 24pt 이하 숫자, 파란 라운드 버튼, 아이콘 5탭, 회색 플레이스홀더. 브랜드가 드러나는 앱은
> **화면마다 "무대" 하나**(브랜드 색 풀블리드 / 풀블리드 사진 / 거대 숫자 / 거대 워드마크)를 두고,
> 나머지는 그 무대를 받쳐 준다.

> **레퍼런스 링크 안내:** 이 문서의 사이트명·링크(mobbin.com 등)는 스킬을 만들 때 리서치한 **출처 표기**다. 실행 중에 열거나
> 검색하지 않는다(로그인이 필요하다). 필요한 구도·비율·팔레트는 이미 본문에 옮겨 적었다.

마케팅 문법(히어로·후기·CTA 배너)은 쓰지 않는다. 대신 **실제 앱 관례**(상태바·탭바·시트·스티키 CTA)
위에서 아트 디렉션을 한다. JS 차단 — 모션은 CSS-only(design-trends.md D섹션 안전 열화 규칙).

## 출력 형식

- **한 HTML = 한 앱의 화면 3장 기본**(1440 캔버스 한 줄에 390 프레임은 3장까지 — 4~5장이면 `zoom: .85` 로 한 줄에 맞추거나 2행으로 균형 있게). 데스크톱 폭 캔버스(아트보드) 위에 폰 프레임을 가로로 나열하고,
  각 프레임 아래 화면명 캡션(12px, `홈` `상품 상세` `장바구니`…). 캔버스 배경은 앱 팔레트와 대비되는
  중립 톤(#EDEDEB 또는 #16161A) + 좌상단에 앱명·아키타입·모드 한 줄.
- 캔버스는 `display:flex; flex-wrap:wrap; gap:48px; align-items:flex-start` — 좁은 뷰포트에서 자동으로 세로 스택.
- 화면 구성은 인터뷰 '핵심 화면' 답에서 고르되, **하나의 사용자 흐름으로 이어지게**(홈 → 상세 → 결제/예약 → 완료).
- 쇼케이스 모드면 첫 프레임을 **스플래시·온보딩 또는 가장 극적인 화면**으로.
- "둘 다"면 폰 프레임 3장 + 그 앱의 소비자형 웹 화면 1장(1280px 폭 프레임, 아래 '웹 앱' 절)을 같은 캔버스에.

## 폰 프레임 규격 (iPhone 390 × 844)

```css
.phone { width: 390px; height: 844px; border-radius: 55px; overflow: hidden; position: relative;
  background: var(--bg); box-shadow: 0 0 0 10px #111, 0 30px 80px rgb(0 0 0 / .35); flex: none; } /* 프레임 그림자는 캔버스 장치 — '그림자 금지' 규칙은 화면 안 UI에만 적용 */
.screen { position: absolute; inset: 0; overflow-y: auto; scrollbar-width: none; padding: 54px 0 120px; }
.island { position: absolute; top: 11px; left: 50%; translate: -50% 0; width: 126px; height: 37px; border-radius: 20px; background: #000; z-index: 50; }
.status { position: absolute; top: 0; inset-inline: 0; height: 54px; display: flex; justify-content: space-between;
  align-items: center; padding: 6px 32px 0; font: 600 17px/1 var(--font-ui); z-index: 40; }
.home-ind { position: absolute; bottom: 8px; left: 50%; translate: -50% 0; width: 134px; height: 5px; border-radius: 3px; background: currentColor; z-index: 60; }
```
- 상태바: 좌 `9:41`, 우 신호·와이파이·배터리 **인라인 SVG**. 풀블리드 히어로 위에서는 글자색 반전(`.on-dark`).
- 풀블리드 히어로는 상태바 뒤(top 0)까지 확장한다 — 콘텐츠 영역만 54px 내린다.
- 스크롤 끝 콘텐츠가 탭바·스티키 CTA에 가려지지 않게 `padding-bottom: 120px`.
- 아이콘은 인라인 SVG(1.5~2px 스트로크, 24px). **이모지 아이콘 금지**(3D 오브젝트 느낌이 필요하면 아래 'CSS 오브젝트').
- 본문 크기: 15~17px, 캡션 12~13px, 라벨 11px. 터치 타깃 44px 이상.

## 스탠다드 vs 쇼케이스 — 같은 정보 구조, 6개 레버

| 레버 | 스탠다드 | 쇼케이스 |
|---|---|---|
| ① 배경·무대 | 흰/연회색, 섹션 동일 | **브랜드 색 풀블리드 또는 사진이 화면 상단 40~100%**, 섹션마다 배경 리듬 |
| ② 최대 요소 크기 | 제목 24~28pt | **요소 1개를 64~120pt 또는 폭 70%+**(숫자·워드마크·헤드라인), 본문 대비 3배+ |
| ③ 디스플레이 폰트 | 본문 폰트 굵게 | **아키타입 디스플레이 폰트**(컨덴스드·디돈·라운드 헤비·세리프) |
| ④ 이미지·오브젝트 | 아이콘·썸네일 | **사진 60~100% / CSS 3D 오브젝트 / 마스코트 / 아트워크 틴트** |
| ⑤ 내비게이션 | 아이콘+라벨 5탭 | **아키타입 탭바**(텍스트만 / 플로팅 글래스 캡슐 / 탭바 생략 + 하단 예약 바) |
| ⑥ CTA 형태 | 파란 라운드 풀폭 | **브랜드 문법**(검정 사각 / 사진 위 흰 pill / 네온 pill / 하드 섀도 / 가격 내장 버튼) |

**스탠다드 앱의 '과감함'**(인터뷰 라운드 4) = 스탠다드 기준에서 바꾸는 레버 수: 절제 1~2개(보통 ①·③) / 균형 3개 / 과감 4개.
**쇼케이스 앱의 '연출 강도'** = 레버 전부 + 모션 세트: 시네마틱 → 풀블리드 사진·영상 무대 + 다크 + 글로우 호흡·캐러셀 /
키네틱 → 거대 숫자·워드마크 + 카운트업·링 채움·경로 드로잉 / 갤러리 → 사진 60~100% + 캐러셀·룩북 스와이프 암시.

쇼케이스는 여기에 **모션 힌트 2~3개**(아래 '모션')를 더한다. 두 버전을 나란히 보면 "같은 앱의 다른
아트 디렉션"으로 읽혀야 한다 — 정보 구조까지 바꾸지 않는다.

**radius는 아키타입 토큰으로 고정한다**(화면 안에서 섞지 않는다): 인덱스·매거진·포스터 0(사진 위 pill만 999) /
하이프 다크 12~14 / 웜 크래프트 12 타일 + 999 버튼 / 마켓플레이스 16~24 / 콰이어트 럭셔리 0~6 / 마스코트 16~20 /
계기판 16~20 / 미디어 8(썸네일)·999(컨트롤).

## 아키타입 카탈로그 (A1~A13)

각 = 무드 / 팔레트 / 타이포(pt = CSS px 기준 390폭 — **웨이트는 실앱 라틴 UI 관찰값, 국문에 적용할 땐 600 상한**) / 레이아웃 / 내비 / 시그니처 / 모션 / 레퍼런스.
hex는 관찰 근사치 — 브랜드 컬러가 있으면 공식만 가져온다.

"오늘" 하이라이트 컬럼 + 막대 위 값 라벨, 대문자 자간 라벨 + 색 1~2개. 결산형: 한 화면에 수치 1개(120pt) + 사진 콜라주.

**온보딩·스플래시** — 스탠다드: 일러스트 + 제목 + 설명 + 도트 + CTA. / 쇼케이스: **단색 풀스크린 스플래시**(브랜드 레드·오렌지+세리프·
파스텔 핑크 + 엠보스 워드마크), 풀블리드 인물 + 중앙 로고 + 하단 흰 pill, 상단 스토리형 세그먼트 진행 바, 선택 단계는 세리프 대형
리스트(A7) 또는 마스코트 말풍선 + 두꺼운 선택 카드(A11), 충격 수치형(48pt 그라데이션 숫자 + 위아래 흐린 숫자 = 롤링 피커 모양).

**페이월** — 스탠다드: 체크 리스트 + 월/연 카드 + CTA. / 쇼케이스: 다크 우주·그라데이션 + 세리프 헤드라인 + 체험 타임라인 3단계,
Free vs Premium 표에서 Premium 열만 컬러 캡슐 헤더 + 하이라이트 컬럼, 카드 모서리를 뚫고 나온 `추천` 뱃지, 56px 풀폭 캡슐 CTA.
([Sweatcoin](https://mobbin.com/screens/0b90a8ac-5732-45f2-9e37-f9078a9d3795) · [Opal](https://mobbin.com/screens/f874f93b-8ef4-408a-bd23-101d703c2ae1))

**장바구니·결제** — 스탠다드: 상품 행 → 요약 → 결제수단 → 검정 풀폭 pill. / 쇼케이스: 타이틀 자체를 디스플레이로(`장바구니` 34pt 익스텐디드),
SSENSE식 표 레이아웃 + 하단 분할 바(좌 합계 / 우 검정 사각), 가격을 버튼 안에(`주문하기 · ₩12,800`) + 하드 섀도, 결제 직후 리워드 카드.

**프로필·멤버십** — 스탠다드: 아바타 + 설정 리스트. / 쇼케이스: **멤버십 카드가 히어로**(브랜드 색 카드 + 등급 엠블럼 + 진행 아크 /
그라데이션 카드 + 바코드 / 검정 메탈릭 카드 + 숫자 통계 / 사진 카드 + QR + 2×2 선 그리드 메뉴).

**예약** — 스탠다드: 인원 원형 칩 + 월 캘린더 + 시간 슬롯 + 풀폭 CTA. / 쇼케이스: 사진 상단 50% + radius 24 시트 + 세리프 30pt 제목,
다크 플로팅 예약 패널, 이벤트는 정사각 포스터 + 옐로 날짜 + `₩0부터 / 예매하기` 옐로 pill 하단 바, 가장자리를 파낸 티켓 모양 카드.

**완료·축하·빈 상태** — 스탠다드: 원형 체크 + "완료!" + 버튼. / 쇼케이스: 중앙 CSS 3D 오브젝트·배지(200px+) + ✦ 스파클 4~6개 +
컬러 헤드라인 24pt + 색 헤더 칩 스탯 타일 3개 + 전폭 CTA, 브랜드 톤 카피("오늘도 지구를 구했어요!"), 스트릭은 거대 숫자 + 7일 체크 행.

## CSS 오브젝트·데이터 시각화 (이미지·JS 없이)

- **링**: `background: conic-gradient(var(--c) calc(var(--p) * 1%), rgb(255 255 255 / .1) 0); -webkit-mask: radial-gradient(farthest-side, #0000 calc(100% - 14px), #000 calc(100% - 13px));`
  끝을 둥글게는 인라인 SVG `<circle stroke-dasharray … stroke-linecap="round">`. 270° 게이지는 `conic-gradient(from 225deg, …)` + 나머지 90° 투명.
- **막대**: flex + `height: %`, 오늘 열은 `rgb(255 255 255 / .06)` 풀하이트 트랙, 값 라벨은 막대 위 absolute.
- **라인**: 인라인 SVG path, `stroke-width: 2.5`, 면은 linearGradient opacity .3→0. 격자 없음(또는 3줄).
- **해치 트랙**: `repeating-linear-gradient(45deg, rgb(255 255 255 / .06) 0 4px, #0000 4px 8px)`.
- **바코드 분포**: `repeating-linear-gradient(90deg, var(--c) 0 2px, #0000 2px 5px)` + mask로 높이 곡선.
- **거대 숫자**: `font-variant-numeric: tabular-nums; letter-spacing: -.04em; line-height: .9;` 단위·소수점은 `<small>` 0.5em.
- **3D 구체·보석·버튼**: 다중 radial-gradient 하이라이트 + `filter: drop-shadow(0 12px 16px rgb(0 0 0 / .18))`. 3D 버튼은 `box-shadow: 0 4px 0 <darker>`.
- **아트워크 틴트**: `--art: #1E4FD8; background: linear-gradient(180deg, var(--art) 0%, color-mix(in oklab, var(--art) 40%, #121212) 38%, #121212 70%);`
  블러 틴트는 아트워크를 `inset: -20%`로 복제해 `filter: blur(60px) saturate(1.4); opacity: .7`.
- **사진 톤 블록**(유효 이미지 없을 때만): `radial-gradient(120% 80% at 30% 20%, #c9a27a, #3b2a20 70%)` + 그레인. 회색 박스 금지.
- **CSS 실물 카드**: 1.586:1 비율, radius 14, 다중 그라데이션 + 칩(작은 radius 4 사각) + `rotate: -6deg`로 겹쳐 쌓기.

## 탭바·시트·스티키 CTA

- **클래식 탭바**: 높이 83(49+34), `background: rgb(255 255 255 / .85); backdrop-filter: blur(20px) saturate(180%)`, 상단 0.5px 헤어라인, 아이콘 24 + 라벨 10.
- **플로팅 글래스 캡슐**(2025~26 주류): `left/right: 16px; bottom: 24px; height: 62px; border-radius: 31px; background: rgb(255 255 255 / .12); backdrop-filter: blur(24px) saturate(180%); border: 1px solid rgb(255 255 255 / .18);` 활성 탭은 내부 캡슐. 옆에 분리된 원형 FAB(62px) 가능. 미니플레이어는 그 위 8px.
- **텍스트 탭**(A1): 11px 대문자, 활성 아래 3px 점. **탭바 생략 + 하단 예약 바**(A7).
- **바텀시트**: `border-radius: 24px 24px 0 0` + 그래버(36×5, #D1D1D1) + 위 그림자. 뒤 화면은 `scale(.94)` + 딤 `rgb(0 0 0 / .4)`로 iOS 시트 스택 흉내.
- **스티키 CTA**: 스크롤 컨테이너 안 `position: sticky; bottom: 0` 또는 프레임 기준 absolute. 플로팅 캡슐(인셋 16, radius 24, 그림자) / 분할 바(`grid 1fr 1fr`).

## 모션 (CSS-only · 쇼케이스 2~3개, 스탠다드 0~1개)

전부 `@media (prefers-reduced-motion: no-preference)` 안, 기본 상태 = 완성형.
- **링 채움**: `@property --p { syntax: '<number>'; inherits: false; initial-value: 0; }` + `animation: fill 1.2s ease-out both` — 기본값은 최종 %로 두고 keyframes `from { --p: 0 }`.
- **숫자 카운트업**: `@property --n` + `counter-reset: n var(--n); content: counter(n)` — 정수만.
- **경로 드로잉**: `stroke-dasharray: 1000; animation: draw 1.4s both` + `@keyframes draw { from { stroke-dashoffset: 1000 } }`.
- **글로우 호흡**: opacity·scale 4~6s infinite alternate. **스파클**: scale 0→1→0 스태거.
- **이퀄라이저**: 막대 3개 `scaleY` 스태거(`transform-origin: bottom`). **가사 하이라이트**: opacity 전환.
- **버튼 펄스**: box-shadow 0→20px 확산 fade(START·녹음 버튼 1곳).
- **캐러셀**: `overflow-x: auto; scroll-snap-type: x mandatory;` + 다음 카드 20~40px 노출 + 도트/카운터 `1/27`.
- **정적 캡처에서도 모션이 읽히게**: 잘린 다음 카드, 진행 중 링, 반쯤 채운 진행 바, 떠 있는 미니플레이어 — "움직일 것 같은" 상태를 그린다.

## 안티패턴 → 처방

1. 모든 카드가 같은 크기 흰 박스 → 히어로 모듈 1개를 2~3배로, 모듈마다 다른 시각 장치.
2. 숫자 24pt 이하 → 핵심 KPI 1개 64~120pt, 단위 30~40% 분리.
3. 파란 #3B82F6 + 회색 → 브랜드 1색을 '무대'에, 보조색은 상태용 1~2개.
4. 라인 아이콘만, 사진 없음 → 사진·아트워크 자리 / CSS 3D 오브젝트 / 마스코트 실루엣 중 하나 필수.
5. 폰트 1종 1굵기 → 아키타입 디스플레이 + 11pt 대문자 자간 +0.08em 라벨로 대비.
6. 기본 라인 차트 + 격자 + 범례 → 격자 제거, 오늘·현재 하이라이트, 값 직접 라벨, 색 1~2개.
7. 평평한 흰 탭바 + 라벨 5개 → 아키타입 탭바(텍스트 / 플로팅 글래스 / 생략+예약 바).
8. 완료·빈 상태를 체크 아이콘으로 끝냄 → 오브젝트·배지 + 컬러 헤드라인 + 스탯 타일 + 브랜드 톤 카피.
9. 라이트만 → 미디어·헬스·명상은 다크 기본(#0B0F12~#151517 + 컬러 글로우, 순흑 지양).
10. 균일한 16px 여백 → 섹션 간 32~40, 모듈 내 12, 히어로 텍스트는 하단 정렬.
11. 배지·할부 문구 난립(드럭스토어형) → 화면당 배지 2개 이하.
12. 목데이터가 가짜 같음(홍길동·₩10,000 라운드·전부 같은 날짜) → 실제 같은 이름·₩12,800·분산된 시각. 브랜드명·수치·후기는 주어진 것만(design-rules §7).
